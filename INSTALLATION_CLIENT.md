# TikTok Live Monitor - Guide d'Installation Client

## 📥 Installation

1. Téléchargez le fichier `TikTokLiveMonitor.exe`
2. Placez-le dans un dossier de votre choix (ex: `C:\Program Files\TikTokLiveMonitor\`)
3. Double-cliquez sur `TikTokLiveMonitor.exe` pour lancer l'application

## ✅ Système requis

- Windows 7 ou supérieur
- Connexion Internet
- Aucune installation supplémentaire requise

## 🚀 Utilisation

1. **Lancer l'application** : Double-cliquez sur `TikTokLiveMonitor.exe`
2. **Entrer le username TikTok** : Entrez le nom d'utilisateur TikTok (sans @)
3. **Démarrer la surveillance** : Cliquez sur "▶ Démarrer"
4. **Télécharger les résultats** : Cliquez sur "💾 Télécharger PDF" pour exporter les numéros détectés

## 📋 Fonctionnalités

- ✅ Détection automatique des numéros de téléphone (8 chiffres)
- ✅ Affichage en temps réel des commentaires
- ✅ Export PDF avec Time, User, Phone, Suite Commentaire
- ✅ Interface moderne et intuitive

## ⚠️ Note importante

- L'antivirus peut afficher un avertissement lors du premier lancement (faux positif courant)
- Vous pouvez autoriser l'exécution en toute sécurité
- L'application nécessite une connexion Internet pour fonctionner
